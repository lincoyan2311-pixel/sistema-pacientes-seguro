# Antes de entregar

1. Lee el código y ejecuta `python app.py` para poder explicarlo con tus palabras.
2. Completa nombre, asignatura, docente y sección en la portada del informe.
3. Si el docente exige GitHub Copilot específicamente, repite el prompt documentado
   en la sección 14 y reemplaza la evidencia por una captura propia.
4. SonarQube quedó pendiente porque este equipo no tenía Docker. Ejecútalo en un
   equipo con Docker Desktop y agrega las métricas reales al informe.
5. Confirma que no existan datos reales, tokens, contraseñas, `venv/` ni archivos
   `datos/pacientes.*` dentro de la carpeta que vas a entregar.

No inventes resultados de herramientas. Si una actividad queda pendiente, indícalo
de forma clara o complétala antes de la entrega.
